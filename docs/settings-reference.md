# Справочник настроек

Все настройки Switchkey хранятся в стандартном хранилище macOS (UserDefaults), в домене
`com.artembeletskiy.switchkey`, то есть в файле
`~/Library/Preferences/com.artembeletskiy.switchkey.plist`. Здесь перечислены все ключи этого
домена: что каждый делает, какое у него значение по умолчанию и где он меняется в окне настроек.

Как пользоваться настройками в окне — в [руководстве](guide.md). Что и где Switchkey хранит
помимо этого файла — в разделе [Приватность и безопасность](privacy.md#что-и-где-хранится).

## Поиск настройки

Если не помните, где настройка живёт, введите её название в поле поиска над списком разделов в окне
настроек: Switchkey покажет подходящие настройки и разделы и откроет нужный раздел. Поиск ищет по
названиям, как они написаны в окне.

## Как читать таблицы

- **Ключ** — имя в домене `com.artembeletskiy.switchkey`.
- **Тип** — Bool (YES/NO), Int, Double, String, массив, словарь или Data.
- **По умолчанию** — значение, которое действует, пока ключа нет в файле. Многие ключи
  появляются в файле только после того, как вы впервые меняете настройку.
- **Где меняется** — раздел окна настроек (вид «Всё») и название строки. «Скрытая» — в окне
  настроек такой строки нет, значение меняется только командой `defaults write`.

Сочетания клавиш хранятся тремя ключами: код клавиши (`…KeyCode`, −1 — сочетание не назначено),
маска модификаторов (`…Mods` или `…Modifiers`) и подпись для показа (`…KeyLabel`). Маска — сумма
значений: ⇧ 131072, ⌃ 262144, ⌥ 524288, ⌘ 1048576. Назначайте сочетания в окне настроек: там
Switchkey проверяет, что сочетание не занято другой функцией.

Скрытые настройки меняйте при закрытом Switchkey командой
`defaults write com.artembeletskiy.switchkey <ключ> <значение>`.

## Исключения

| Ключ | Тип | По умолчанию | Что делает | Где меняется |
|---|---|---|---|---|
| `appExceptionModes` | словарь | пусто | Bundle id программы → `off` («Выкл») или `soft` («Мягкий») | «Исключения» → «Программы-исключения» |
| `appForcedLayouts` | словарь | пусто | Bundle id программы → `en` или `ru`: раскладка, которая включается при переходе в программу | Там же, выбор раскладки слева от режима |
| `rememberAppLayout` | Bool | NO | Запоминать раскладку в каждой программе (сама память на диск не пишется) | «Исключения» → «Запоминать раскладку в каждой программе» |
| `exceptionsBlockManual` | Bool | NO | В программах с режимом «Выкл» не работает и ручное исправление | «Исключения» → «Отключать и ручное исправление» |
| `ignoredWords` | массив строк | `вк`, `тг`, `vk` | Слова, которые никогда не переключаются. Три слова добавляются один раз при первом запуске; удалённые не возвращаются | «Исключения» → поле «Слово…» |
| `forceSwapWords` | массив строк | пусто | Выбранный вариант неоднозначных слов: слово из списка всегда приводится к этому варианту | «Исключения» → «Неоднозначные слова» → «Открыть список…» |
| `wordRulesEnabled` | Bool | NO | Применять правила для слов | «Исключения» → «Применять правила» |
| `wordRules` | массив пар | пусто | Правила: пара «вид, образец». Виды: `prefix` («Начинается с»), `contains` («Содержит»), `suffix` («Заканчивается на»), `regex` («Регулярное выражение») | «Исключения» → поле «Текст или выражение…» |
| `learnOnUndoEnabled` | Bool | YES | После третьей отмены исправления одного и того же слова Switchkey предлагает добавить его в исключения | «Исключения» → «Учиться на отмене» |
| `learnedWords` | массив строк | пусто | Слова, добавленные по такому предложению. Хранятся открытым текстом | «Исключения» → «Учиться на отмене», кнопка «Очистить» |
| `undoStrikeCount` | словарь | пусто | Число отмен по каждому слову. Ключи — отпечатки слов (SHA-256 с солью), а не сами слова | Служебная |
| `undoStrikeTime` | словарь | пусто | Время последней отмены по каждому отпечатку; счётчики со временем затухают | Служебная |
| `undoDeclinedWords` | массив строк | пусто | Отпечатки слов, по которым вы ответили «Не надо»: о них Switchkey больше не спрашивает | Служебная |
| `undoFingerprintSalt` | Data | создаётся при первой отмене | Соль для отпечатков, 16 случайных байт. Если её удалить, сохранённые отпечатки перестанут совпадать со словами | Служебная |
| `seededDefaultApps` | массив строк | пусто | Bundle id программ, которые Switchkey сам добавил в «Программы-исключения». Нужен, чтобы удалённая вами программа не вернулась в список | Служебная |

## Резервная копия и сброс

> **Внимание.** Файл настроек и его копия содержат открытым текстом автозамену, сниппеты для
> вставки, слова-исключения, правила для слов, выученные слова и личный словарь опечаток. Храните
> копию так же бережно, как сами эти данные: не отправляйте её другим людям и не кладите в
> общедоступные хранилища.

Перед любой из команд ниже закройте Switchkey: меню значка → «Выйти». При выходе Switchkey
возвращает клавише 🌐 системное действие и снимает переназначение Caps Lock, а пока он
запущен, он может перезаписать файл своими значениями.

Посмотреть все настройки:

```bash
defaults read com.artembeletskiy.switchkey
```

Сохранить копию на рабочий стол:

```bash
defaults export com.artembeletskiy.switchkey ~/Desktop/switchkey-settings.plist
```

Восстановить настройки из копии (текущие значения заменяются значениями из файла):

```bash
defaults import com.artembeletskiy.switchkey ~/Desktop/switchkey-settings.plist
```

Сбросить все настройки:

```bash
defaults delete com.artembeletskiy.switchkey
```

Вернуть одну настройку к значению по умолчанию — удалить её ключ, например:

```bash
defaults delete com.artembeletskiy.switchkey soundName
```

После полного сброса следующий запуск Switchkey считается первым: снова откроется окно первого
запуска, включится запуск при входе в систему, окно настроек откроется в виде «Основное», режим
диктовки станет «Нажимать», а в исключения вернутся `вк`, `тг` и `vk`. История, аудио, пароль на
историю и модели распознавания при этом не затрагиваются: они хранятся не в этом файле. Доступы
«Универсальный доступ» и «Мониторинг ввода» тоже сохраняются.
