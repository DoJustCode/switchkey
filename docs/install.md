## Требования

- Mac с Apple Silicon (M1 и новее) и macOS 14 Sonoma или новее.
- Перевод выделенного — macOS 15 или новее. Запись разговора — macOS 14.2 или новее.
- Место на диске: основное занимают модели распознавания — Parakeet около 465 МБ, Whisper от
  142 МБ до 1,6 ГБ. Скачивать нужно только ту модель, которой вы пользуетесь.

## Установка

1. Скачайте `Switchkey-<версия>.dmg` со
   [страницы выпусков](https://github.com/DoJustCode/switchkey/releases/latest).
2. Откройте образ и перетащите Switchkey на папку «Программы».
3. Запустите Switchkey из «Программ». Не запускайте его прямо из образа: из временной папки
   macOS не сохранит разрешения.

Программа подписана сертификатом разработчика и проверена Apple, поэтому открывается без
предупреждений. Проверить, что файл не изменён по дороге, можно по контрольной сумме: она
указана на странице выпуска.

```bash
shasum -a 256 ~/Downloads/Switchkey-1.0.0.dmg
```

## Первый запуск

Откроется окно «Добро пожаловать в Switchkey».

1. **Разрешения.** Нажимайте подсвеченную кнопку «Разрешить…» по очереди:
   - «Универсальный доступ» — чтобы исправлять раскладку и работали сочетания клавиш;
   - «Мониторинг ввода» — чтобы видеть нажатия;
   - «Микрофон» — только для диктовки, шаг можно пропустить.

   Кнопка сама открывает нужный раздел «Системных настроек» — останется включить Switchkey.
   Если его нет в списке, нажмите «+» под списком и выберите Switchkey в «Программах».
2. **Диктовка.** «Скачать» — модель распознавания Parakeet, нужна один раз.
3. **Перевод** (macOS 15 и новее) — установка языкового пакета «Русский ↔ английский».
4. **Попробуйте.** Наберите в поле `ghbdtn` и пробел — слово исправится само.
5. «Готово».

Окно можно открыть снова: «Настройки» → «О программе» → «Знакомство».

Если одновременно запущен Punto Switcher, Switchkey предложит его закрыть и убрать из объектов
входа: вместе переключатели мешают друг другу.

## Обновление

Switchkey не обновляется сам и не проверяет обновления: программа не выходит в интернет без
вашей кнопки. Новые версии появляются на
[странице выпусков](https://github.com/DoJustCode/switchkey/releases).

1. Закройте Switchkey: меню значка → «Выйти».
2. Скачайте новый образ и перетащите Switchkey в «Программы» с заменой.
3. Запустите его.

Настройки, история и модели сохраняются. Если после обновления исправление не работает, хотя
Switchkey включён в списке «Универсального доступа», удалите его из списка кнопкой «−» и
добавьте снова через «+».

## Перенос настроек на другой Mac

1. На старом Mac: «Настройки» → «Общие» → «Перенос на другой Mac» → «Сохранить настройки в
   файл…».
2. Перенесите файл на новый Mac (AirDrop, флешка).
3. На новом Mac: там же «Загрузить из файла…». Switchkey попросит подтвердить замену и
   перезапустится.
4. Удалите файл: он не зашифрован, сниппеты и автозамена лежат в нём открытым текстом.

В файл не попадают служебные отметки, выбранный микрофон, размеры окон и включённый вручную
приватный режим — они относятся к конкретному Mac. Загрузка не может ослабить приватность: она
не включает историю буфера, историю диктовки и сохранение записи голоса, если на этом Mac они
выключены. История не переносится: её ключ хранится в связке ключей старого Mac.

## Полное удаление

1. Закройте Switchkey: меню значка → «Выйти». При выходе он возвращает системе клавишу 🌐 и
   Caps Lock, если вы их переназначали.
2. Удалите приложение:

   ```bash
   rm -rf /Applications/Switchkey.app
   ```

3. Удалите историю, модели, журнал и настройки:

   ```bash
   rm -rf ~/Library/Application\ Support/Switchkey
   ```

   ```bash
   rm -f ~/Library/Logs/Switchkey.log
   ```

   ```bash
   defaults delete com.artembeletskiy.switchkey
   ```

   Модели Parakeet лежат в `~/Library/Application Support/FluidAudio/`. Удалите эту папку, если
   её не использует другая программа.
4. Удалите ключ шифрования истории из связки ключей:

   ```bash
   security delete-generic-password -s com.artembeletskiy.switchkey.voicehistory
   ```

5. Сбросьте выданные разрешения:

   ```bash
   tccutil reset All com.artembeletskiy.switchkey
   ```

6. Проверьте, что Switchkey не осталось в «Системные настройки» → «Основные» → «Объекты входа».
